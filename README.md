# 距离边界认证仿真 · 中继攻击防御演示

验证一套能抵御**中继攻击（relay attack）**的近距离认证方案：车端与钥匙之间进行
Hancke–Kuhn 式快速挑战—应答，逐轮测量往返时延（RTT），用无线电传播的光速下界
`2d/c` 约束真实距离。中继设备无论怎么转发，都只能**增加**空中绕路（三角不等式）
和设备处理时延，无法缩短 RTT，因此攻击会被物理规律检出。

## 运行

前置：Rust（含 `wasm32-unknown-unknown` target）与 [trunk](https://trunkrs.dev/)。

```bash
# 1) 核心库测试（16 个单元测试，含物理不变量与统计单调性）
cargo test -p db-core

# 2) 主机端命令行演示
cargo run -p db-core --example demo

# 3) Yew 界面（默认 http://127.0.0.1:8080）
cd web && trunk serve

# 4) 发布构建（产物在 web/dist）
cd web && trunk build --release
```

> 若环境无法访问 GitHub 下载 binaryen，`index.html` 已将 `data-wasm-opt` 设为 `0`
> 跳过 wasm-opt；Rust 侧仍保留 `lto = true` 与 `opt-level = "s"`。

## 协议与判定模型

快速阶段共 N 轮，车端每轮发一个挑战比特，钥匙立即应答，车端测量 RTT：

```
RTT = 2 × 空中传播时延（路径总长 L，去程+回程）
    + 钥匙快速应答处理（均值 μ_k，高斯抖动 σ_k）
    + 2 × 每台中继的转发处理（去程、回程各一次，均值 μ_r，抖动 σ_r）
    + 车端测量噪声（σ_m）
```

- 单轮 `RTT > 门限 T` 记一次超时；信道误码记一次位错；
- 失败轮数（超时 + 位错）超过 `max_fail_rounds` 即**拒绝**；
- 门限扣除钥匙标称处理后按 `2d/c` 折算为“等效距离”，界面以蓝色虚线圆画出。

中继路径按实际布点逐跳建模：直连 / 单中继 / 双中继（含可选的中继间回传时延）。
`Scenario::rtt_floor_ns` 给出不含任何抖动的确定性下界，可直接对照“物理上是否必然超时”。

## 界面能做什么

- **拖拽布点**：车辆 🚗、钥匙 🔑、两台中继 📡 可在 20×14 m 场地上任意拖动，
  实时显示直线距离、消息路径长度、RTT 下界与门限等效半径；
- **三个预设**：合法近距、经典双中继盗窃（钥匙在屋内、中继贴车贴门）、临界对抗；
- **全参数可调**：门限、轮数 N、容错轮数、钥匙处理时延与抖动、测量噪声、BER、
  中继模式（模拟放大 25 ns / 解码转发 200 ns）、回传时延；
- **单次认证**：逐轮 RTT 表 + 放行/拒绝判定；
- **蒙特卡洛统计**：每场景 200/1000/4000 次，输出当前门限下的
  **FRR（误拒率）** 与 **FAR（漏放率）**，并扫描整条门限曲线、标出 EER 与推荐工作点。

## FRR / FAR 的取舍

| 门限方向 | FRR（合法被拒） | FAR（攻击放行） | 含义 |
|---|---|---|---|
| 收紧（等效距离更小） | ↑ | ↓ | 更安全，但用户掏钥匙的失败体验变多 |
| 放松 | ↓ | ↑ | 体验顺滑，但中继攻击面变大 |

- **EER（等错误率点）**只衡量诚实分布与攻击分布的可分性，不是推荐车规配置；
- 车辆场景下“漏掉一次盗车”的代价远高于“让用户多等一秒/多掏一次手机”，
  因此程序默认给出**安全优先推荐点**：在 `FRR ≤ 1%` 约束下取最小门限，
  把 FAR 压到趋近于 0；
- 增大 N 或合理设置容错轮数可以平均掉单轮随机抖动，但 BER 高时过度收紧容错
  反而推高 FRR；这些都可以在界面上直接扫出来。

默认参数（N=32、门限 150 ns ≈ 等效 10.5 m、钥匙处理 80±4 ns）下，
1.5 m 合法近距的 FRR 与典型双中继攻击的 FAR 在 4000 次仿真中均为 0。

## 设计边界（仿真不覆盖什么）

- 密码学层假定安全（应答比特不可伪造，对应 FiRa / CCC Digital Key 的 UWB 距离边界），
  仿真只聚焦“距离”维度；
- 物理层建模为高斯抖动 + 独立 BER，未建模多径/非视距（NLOS）偏差与距离缩减攻击
  （distance reduction）的高级物理对抗——后者需要天线级仿真，不在本项目范围；
- 所有随机数来自确定性 SplitMix64，同种子结果可复现，便于回归与演示。
